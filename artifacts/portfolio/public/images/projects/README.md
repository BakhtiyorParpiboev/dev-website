# Public project walkthroughs

Owner-supplied annotated screenshots from `AI-Website-Builder-Intro-Annotated` and
`Friendly-Platform-Intro-Annotated`, captured October 29, 2026. Ten images per
project, converted to WebP without changing the annotations. The originals and
QA notes remain in the owner's supplied folders.

The screenshot title/caption manifest is `src/lib/project-galleries.ts`.
Gallery assets are public and intended for published project case studies.
Only the published detail UI displays them; these are not private admin uploads.

These images demonstrate UI and intended workflows, not full end-to-end checks.
Friendly uses QA data; AI funding and Calendar verification limitations are
marked. AI Web Builder controls were not all exercised during capture; Stripe
is test mode. Public content should preserve those distinctions.
